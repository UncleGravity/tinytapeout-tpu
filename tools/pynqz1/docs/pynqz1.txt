PYNQ-Z1 Board

Reference Manual:
https://digilent.com/reference/programmable-logic/pynq-z1/reference-manual

Setup:
https://pynq.readthedocs.io/en/latest/getting_started/pynq_z1_setup.html

- Board hostname: pynq.
- SSH user: xilinx.
- Default password, if needed: xilinx.
- OS verified: PynqLinux 3.0, Ubuntu 22.04 based.
- PYNQ package is in virtualenv:
  /usr/local/share/pynq-venv/bin/python
- PYNQ version verified: 3.1.1.
- XRT sees device after adding xilinx to video/render groups.
- Jupyter listens on ports 80 and 9090.

Use this shape for SSH-driven PYNQ tests:
nix develop -c ssh xilinx@pynq 'sudo env XILINX_XRT=/usr PYNQ_PYTHON=python3.10 /usr/local/share/pynq-venv/bin/python your_test.py'

Board runtime workflow from tools/pynqz1:
nix develop -c nix run .#pynq-board -- daemon

In a second terminal:
nix develop -c nix run .#pynq-board -- hello
nix develop -c nix run .#pynq-board -- smoke --bytes 1536k
nix develop -c nix run .#pynq-board -- graph-copy-smoke --bytes 1536k

The daemon command syncs runtime/ to /home/xilinx/pynqz1-runtime before it
starts bonsaid in the foreground. Use `pynq-board sync` for copy-only updates
or `pynq-board daemon --no-sync` to run already-copied board files.

Smoke test passed: base.bit loaded, DDR-backed allocate() buffer worked.

nix develop -c scp tools/pynqz1/mem_bandwidth.py xilinx@pynq:/home/xilinx/
